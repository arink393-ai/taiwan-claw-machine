# 🇹🇼 台灣經典「飛絡力」線上夾娃娃機 (Fei Lou Li Claw Machine)

專為台灣夜市與夾娃娃機文化量身打造的經典**「飛絡力 (FEILUOLI)」選物販賣機二代**網頁小遊戲！還原真實機台手感、物理甩爪、二停收爪技巧、保證取物（保夾）機制與台主機板微調後台。

## 🌟 機台特色與還原細節

1. **經典飛絡力亮黃色外觀 (Authentic Yellow Cabinet)**
   - 經典飛絡力標準亮黃烤漆機身、頂部霓虹跑馬燈招牌（「飛絡力」「選物販賣機 二代」「保證取物」）。
   - 壓克力全景透明櫥窗、鏡面反射、上方聚光燈照明、左前方出貨洞口與標準防甩壓克力擋板。
   - 底部金屬取物推門（點擊可查看戰利品背包）。

2. **復古 LED 數碼儀表板 (Digital Displays)**
   - `[ 投幣 / 剩餘局數 ]` 紅色七段數碼管
   - `[ 保夾金額 ]` 綠色七段數碼管 (預設 300 元)
   - `[ 目前累積金額 ]` 黃色七段數碼管
   - `[ 操作倒數 ]` 藍色七段數碼管 (20 秒倒數)
   - 達到保夾金額時，綠色保夾專用指示燈高頻閃爍，強制切換 100% 強爪直到出貨！

3. **可愛立體畫面 (v2)**
   - 經典飛絡力外觀：亮黃色機身、紅色燈箱招牌、黑黃警示立柱、深色金屬控制台、紅色球搖桿，櫥窗內是綠色地墊
   - 獎品**大小不一**（迷你／標準／大型／特大），洞口有**兩支鐵桿縮口**，台主可調間距
   - 透視房間（背牆彩旗、波點、棋盤地板）、地面接觸陰影、金屬三爪＋粉紅橡膠爪尖、聚光燈與閃爍星光
   - **立體景深（前 / 中 / 後三排貨架）**：W / S 前後移動爪子；越後排越小、越高、顏色越淡，且各排各自堆疊、互不碰撞；爪子只能夾到所在排，地板有黃色亮帶標示目前排，右側指示條顯示景深；洞口與鐵桿只在最前排
   - 出貨時彩帶粒子噴發；機身、按鈕皆為厚實的「玩具感」立體設計，按鈕可按下

3-0. **機頂擺設（參考實機）**：夾換區展示架、刮刮樂、夾出登記板（正字記號）、牛皮紙袋
   - 每夾出一個獎品得**兌換券**（普通 1、稀有 2、超稀有 3、隱藏款 5）
   - 券可在夾換區換**夾換限定品**（15 / 25 / 40 券），或 3 券刮一張**刮刮樂**（可刮開！獎項：加送 1/3/10 局、保夾金額 +100、大獎＝隱藏款公仔）
   - 控制台改為黃綠壓克力板 + 綠色取物鈕 + 水晶球搖桿；爪子是紅銀圓筒、螺旋電線、三支細弧鋼爪

3-1. **18 種獎品、25 款可收集圖鑑**（全部以 Canvas 程式繪製，無外部圖檔）
   - 🧸 療癒娃娃：泰迪小熊、長耳兔兔、水豚君、柴犬、招財貓、企鵝、小恐龍、小黃鴨
   - 🍉 食物抱枕：西瓜、珍珠奶茶、台式排骨雞碗麵
   - 📦 公仔盒：魔法星星、機甲戰士、恐龍派對（透明展示窗內有小公仔）
   - 🎁 盲盒：星願精靈、甜點好朋友、黃金限定 —— 夾出後可**拆盲盒**，抽到系列公仔，8% 機率開出**隱藏款**（黃金盲盒必中稀有以上、隱藏款機率 40%）
   - 🥚 夢幻扭蛋球
   - 戰利品背包是圖鑑：依分類顯示進度，未收集的是剪影；進度存在 localStorage，重新整理不會消失

4. **核心物理與操作技巧**
   - **甩爪物理 (Swinging Claw)**：天車具備單擺慣性，移動時鋼索會產生擺盪；下爪的瞬間爪子會帶著擺動速度，沿甩動方向拋出弧線落下！甩爪比直上直下**更容易夾住、夾得更牢**；直上直下容易夾了一提就鬆開，娃娃留在原地。
   - **二停技巧 (Double-Tap 2nd Stop)**：下爪後繩索下放時，**再次按下下爪鈕**即可立刻煞車提前夾取！適合捏薄物、卡背刺或防止翻倒娃娃。
   - **台灣娃娃機靈魂：二段放爪 / 內丟**：非保夾模式下，爪子在升至頂點或折返時會依設定之二段爪力進行放爪判定。
   - **多樣化台式可愛獎品**：水豚君卡比巴拉、立耳柴犬、背刺三角小恐龍、特大西瓜靠枕、珍珠奶茶杯、重低音盲盒、台式排骨雞碗麵。

5. **100% 原生街機音效 (Web Audio API Synthesizer)**
   - 投幣清脆叮噹聲、搖桿微動開關點擊喀嗒聲、天車步進馬達運轉低頻嗡嗡聲、滑輪下爪音、爪子閉合聲、出貨大獎慶祝樂曲。

6. **台主模式 (DIP Switch Owner Settings)**
   - 點擊「🔑 台主機板設定」，可以像真實台主一樣調校機台：
     - 保證取物金額 (50 ~ 990 元)
     - 抓取電壓 (8V ~ 32V)：電壓越高爪子閉得越緊、越容易夾起
     - 搬運電壓 (8V ~ 32V)：夾起後的力道，太低會中途鬆脫（越重的獎品越明顯）；保夾時兩段鎖在 32V
     - 洞口擋板高度 (15px ~ 90px)
     - 倒數操作秒數 (10s ~ 30s)
     - 一鍵補滿娃娃 (重設山崩台配置)
     - 清除戰利品與統計存檔

## 🕹️ 遊戲操作指南

| 動作 | 鍵盤快捷鍵 | 觸控 / 滑鼠 |
| :--- | :--- | :--- |
| **投幣 10 元** | 按鍵 **[C]** | 點擊投幣孔或「投幣 10 元」按鈕 |
| **投幣 100 元 (10局)** | - | 點擊「投 100 (換10次)」按鈕 |
| **移動方向 / 前後景深 (支援甩爪)** | **[W] [A] [S] [D]** 或 **[方向鍵]** | 拖曳控制台中央的「經典紅色大球搖桿」 |
| **下爪 / 二停** | **[空白鍵 Space]** 或 **[Enter]** | 點擊超大發光「下爪」按鈕（下放中再按一次為二停） |
| **一鍵重新補貨** | 按鍵 **[R]** | 台主設定內「重新補滿娃娃」按鈕 |
| **查看戰利品背包** | - | 點擊頂部「🎒 戰利品背包」或點擊底部「取物口」推門 |
