# 🇹🇼 台灣經典「飛絡力」線上夾娃娃機 (Fei Lou Li Claw Machine)

專為台灣夜市與夾娃娃機文化量身打造的經典**「飛絡力 (FEILUOLI)」選物販賣機二代**網頁小遊戲！還原真實機台手感、物理甩爪、二停收爪技巧、保證取物（保夾）機制與台主機板微調後台。

4. **核心物理與操作技巧**
   - **甩爪物理 (Swinging Claw)**：天車具備單擺慣性，移動時鋼索會產生擺盪；下爪的瞬間爪子會帶著擺動速度，沿甩動方向拋出弧線落下！甩爪比直上直下**更容易夾住、夾得更牢**；直上直下容易夾了一提就鬆開，娃娃留在原地。
   - **二停技巧 (Double-Tap 2nd Stop)**：下爪後繩索下放時，**再次按下下爪鈕**即可立刻煞車提前夾取！適合捏薄物、卡背刺或防止翻倒娃娃。
   - **台灣娃娃機靈魂：二段放爪 / 內丟**：非保夾模式下，爪子在升至頂點或折返時會依設定之二段爪力進行放爪判定。
   - **多樣化台式可愛獎品**：水豚君卡比巴拉、立耳柴犬、背刺三角小恐龍、特大西瓜靠枕、珍珠奶茶杯、重低音盲盒、台式排骨雞碗麵。

5. **100% 原生街機音效 (Web Audio API Synthesizer)**
   - 投幣清脆叮噹聲、搖桿微動開關點擊喀嗒聲、天車步進馬達運轉低頻嗡嗡聲、滑輪下爪音、爪子閉合聲、出貨大獎慶祝樂曲。

6. **台主模式 (DIP Switch Owner Settings)**
   - 點擊「🔑 台主機板設定」，可以像真實台主一樣調校機台：
     - 保證取物金額 (50 ~ 990 元)
     - 抓取電壓 (8V ~ 32V)：電壓越高爪子閉得越緊、越容易夾起
     - 搬運電壓 (8V ~ 32V)：夾起後的力道，太低會中途鬆脫（越重的獎品越明顯）；保夾時兩段鎖在 32V
     - 洞口擋板高度 (15px ~ 90px)
     - 倒數操作秒數 (10s ~ 30s)
     - 一鍵補滿娃娃 (重設山崩台配置)
     - 清除戰利品與統計存檔

如果本地伺服器正在運行，直接在瀏覽器打開：
```
http://localhost:8080/
```
程式檔案：`index.html`、`style.css`、`prizes.js`（獎品圖鑑與繪圖）、`physics.js`（物理與渲染）、`game.js`（遊戲流程）、`audio.js`（音效）。

若要在其他電腦或手機區網遊玩，可使用本機 IP：`http://<您的IP>:8080/`

## 3D 櫥窗

使用本地 Three.js 0.160.1 建立 WebGL 立體獎品、三爪、鋼索、天車、棋盤地板與出貨洞口。上方可切換正面、側面、俯視，操作沿用 WASD／方向鍵、空白鍵二停及 C 投幣。抓取與保夾沿用原有遊戲模擬，並非新增完整剛體物理引擎。WebGL 不可用時自動使用原版 Canvas 畫面。Three.js 授權位於 vendor/THREE-LICENSE.txt。

本機預覽：`python3 -m http.server 8765`，開啟 http://localhost:8765。

參考台灣零食山崩台的多排高堆、彩色包裝與機頂展示。新增 8 種原創零食包裝及 4 種集券夾換禮盒；補貨約 80 件，五層錯位堆疊，抓走支撐物時會擾動附近商品，由既有碰撞模擬產生滑落。正面相機位於中央、水平看向機台；機頂展示附兌換券標籤及刮刮樂展示板。所有投幣與兌換均為遊戲內模擬。

驗證：Chrome 桌面及 390px 手機版，WebGL 畫面、三視角、投幣移動下爪、7 項夾換商品與刮刮樂入口；手機頁面無水平溢出，無 JavaScript 執行錯誤。

### 使用者機台照片外觀更新

依照提供的十張機台照片，改成方形黃色金屬框、紅白描邊招牌、銀色控制台邊條、水晶握柄及金屬投幣面板。3D 爪頭加入紅銀色圓柱、彎曲三爪與黑色螺旋電線。混堆以絨毛娃娃與不同長寬的景品盒為主，增加布面紋理、吊牌、包膜反光、條碼與食物抱枕形狀；機頂刮板採 10 × 10 圓點格狀外觀，沿用遊戲原本的集券刮獎入口。

桌面及手機 390px 已檢查畫面，三視角、投幣、移動、下爪、二停及刮獎入口可用，無 JavaScript 錯誤及手機水平溢出。此為照片造型的程式化 3D 重建，並非照片掃描模型。

### 抓取與洞口旋轉修正

3D 爪子放大為 1.4 倍，抓取判定點對齊爪尖，接觸與抓取共用範圍計算，持有獎品的位置也對齊夾取點。取消預設特大卡洞商品；鐵桿接觸僅在有速度的撞擊時施加旋轉，靜止接觸增加阻尼，避免持續旋轉。

回歸驗證：32 種獎品 × 3 種尺寸的接觸／保夾抓取一致性；洞口大盒模擬 20 秒停止旋轉；Chrome 下爪、二停流程無執行錯誤。

### 機台模式

機台上方可切換山崩台、公仔台、3C 台與娃娃台，各自使用獎品池、堆疊密度、跑馬展示及櫥窗招牌。新增六款可收集的 3C 禮盒：耳機、喇叭、行動電源、手錶、手把與氛圍燈。模式會記住在瀏覽器；待機時可切換，已投幣局數及領獎途中鎖定切換。保夾累積及戰利品維持共用，補貨使用當前模式。

驗證：四模式補貨均符合獎品分類，手機無水平溢出，重整保留 3C 模式，付費局數中禁止切換，完整下爪流程無執行錯誤。
